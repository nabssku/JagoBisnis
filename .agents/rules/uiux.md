# UI/UX Rules

Style:
- clean SaaS
- warm
- minimal
- modern UMKM
- Bisa digunakan di Dark Mode Dan Light Mode

Avoid:
- neon colors
- glassmorphism berlebihan
- terlalu banyak gradient
- Ukuran text dan element terlalu besar dan terlalu kecil, tidak balance

Buttons:
- rounded-xl
- consistent height
- loading state wajib

Cards:
- subtle border
- soft shadow
- padding konsisten
