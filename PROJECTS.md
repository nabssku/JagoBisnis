# JagoBisnis

Platform all-in-one untuk UMKM:
- website builder
- toko online
- dashboard bisnis
- AI content
- social media planner

## Stack
Frontend: Next.js + TypeScript + Tailwind
Backend: NestJS + Prisma
Database: PostgreSQL
Storage: Local Storage

## MVP v1
- Register/login
- Buat profil bisnis
- Dashboard
- Website builder drag and drop
- CRUD produk
- Public website /jagobisnis/[slug]

## Jangan dibuat dulu
- Payment
- Auto-post social media
- Marketplace integration
- Analytics kompleks
